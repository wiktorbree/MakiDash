# MakiDash

MakiDash is a mockup iOS application built with SwiftUI that demonstrates a modern interface for a Japanese cuisine ordering system. This demo app showcases SwiftUI implementation techniques, focusing on sushi and other traditional dishes.

![MakiDashGit](https://github.com/user-attachments/assets/d31d58c9-749c-4f03-ac50-7c4de23bfaa3)

## Features

- 💰 Mock pricing information for menu items
- 📱 Modern, responsive UI built with SwiftUI
- 🎨 Clean and intuitive user interface

## Technical Details

- Built with SwiftUI
- iOS native application
- Clean architecture with separate data service layer
- Modern Swift programming practices
- Static data implementation for demo purposes

## Getting Started

### Prerequisites

- Xcode 14.0 or later
- iOS 16.0 or later
- Swift 5.0 or later

### Installation

1. Clone the repository
```bash
git clone https://github.com/wiktorbree/MakiDash.git
```

2. Open the project in Xcode
```bash
cd MakiDash
open MakiDash.xcodeproj
```

3. Build and run the project in Xcode

## Project Structure

- `MakiDashApp.swift` - Main application entry point
- `DataService.swift` - Mock data service for menu items
- `HomeView.swift` - Main menu display view
- `LoginView.swift` - Demo authentication interface
- `MenuView.swift` - Menu presentation component
- `MenuListRow.swift` - Individual menu item display
- `MenuItem.swift` - Data model for menu items

## Note

This is a demo/mockup application created for educational and demonstration purposes. It does not include actual ordering functionality or backend integration.
